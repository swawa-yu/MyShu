# MyShu の目的
- 週単位で繰り返されるスケジュールを共有する
  - URLを共有することで
    - 権限によってタスクの詳細を確認できるかどうかを切り替えられるといいかも
  - スクリーンショットとして画像をエクスポートすることで
    - スクリーンショットの範囲を楽に選択できると嬉しいかも
- スケジュールを簡単に編集できること
  - スケジュール = イベント名 + (開始時刻 + 終了時刻) + 詳細
  - 色分けできること
  - 時間の幅を簡単に調整できること
  - 編集する範囲を指定できること...例えば「大学の時間だけ」「寝る時間を省略」「24h」など
