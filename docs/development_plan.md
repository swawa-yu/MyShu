# 開発計画

1.  **プロジェクトの初期化:**
    *   既存のソースコードを整理し、新しい開発を始めるための準備をします。
2.  **コア機能の開発:**
    *   **スケジュール表示:** 週単位のカレンダーUIを作成します。
    *   **スケジュール編集:** ドラッグ＆ドロップでの時間変更や、色分けが可能な編集機能を追加します。
    *   **データ管理:** アプリケーションの状態を管理する仕組みを導入します。
3.  **共有機能の開発:**
    *   **URL共有:** スケジュールの状態をURLにエンコードし、そのURLから状態を復元できるようにします。
    *   **画像エクスポート:** 表示されているスケジュール範囲を画像として出力する機能を追加します。
4.  **UI/UXの向上:**
    *   「大学の時間だけ」のように、表示・編集する時間範囲をカスタマイズできる機能を追加します。

# 技術スタック

*   **フレームワーク:** React, TypeScript (既存の構成を維持)
*   **UI:** Tailwind CSS (既存の構成を維持) と Shadcn/UI (高品質なUIコンポーネント群)
*   **状態管理:** Redux Toolkit
*   **画像エクスポート:** html2canvas
